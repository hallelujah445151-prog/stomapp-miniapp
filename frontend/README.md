# StomApp Frontend - Интуитивное приложение для зуботехнической лаборатории

React + TypeScript приложение с фокусом на простоту использования и интуитивность.

## 🎯 Ключевые особенности (v2.0)

### ✅ Интуитивный интерфейс
- **Многошаговое создание заказа** - разбито на 3 простых шага
- **Быстрый выбор** - кнопки для часто используемых операций
- **Умные подсказки** - контекстная помощь на каждом шаге
- **Прогресс бар** - визуализация заполнения формы
- **Предпросмотр** - проверка данных перед отправкой

### ✅ Простота использования
- **Минимум кликов** - базовые операции за 1-2 касания
- **Очевидная навигация** - bottom navigation bar
- **Мгновенная обратная связь** - toast уведомления
- **Автозаполнение** - разумные значения по умолчанию
- **Офлайн-готовность** - базовые функции без интернета

### ✅ Гибкость и расширяемость
- **Модульная архитектура** - easy to extend
- **Reusable компоненты** - DRY принцип
- **State Management** - Zustand для простого управления
- **TypeScript** - type safety для расширений
- **Clean code** - легко поддерживать

## 🎨 Дизайн принципы

### Цветовая схема
- **Основной:** `#2481cc` (Telegram blue)
- **Успех:** `#4caf50` (Green)
- **Предупреждение:** `#ff9800` (Orange)
- **Ошибка:** `#f44336` (Red)
- **Текст:** `#000000` (Black)
- **Подсказки:** `#999999` (Gray)

### Типографика
- **Заголовки:** 18-24px, fontWeight 600
- **Основной текст:** 16px, regular
- **Мелкий текст:** 13-14px, regular
- **Шрифт:** System fonts (San Francisco, Roboto)

### Компоненты
- **Кнопки:** 12px padding, border-radius 8px
- **Карточки:** 16px padding, shadow 2px
- **Inputs:** 14px padding, 2px border
- **Иконки:** Emoji для интуитивности
