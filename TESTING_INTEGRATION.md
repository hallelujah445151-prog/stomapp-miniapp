# Тестирование Telegram Mini App интеграции

## 🤖 Пункт 2: Интеграция с Telegram ботом

### ✅ Созданные файлы:

1. **handlers/mini_app.py** - Handler'ы для Mini App
   - `open_mini_app()` - Открытие Mini App с кнопкой
   - `mini_app_info()` - Информация о Mini App

2. **Обновлен bot.py** - Добавлены команды:
   - `/app` - Информация о Mini App с кнопкой открытия
   - `/miniapp` - Быстрый доступ к Mini App

### 📱 Инструкция по тестированию:

#### 1. Запуск Backend API
```bash
cd mini-app/backend
python main.py
```
Backend должен работать на: `http://localhost:8000`

#### 2. Запуск Frontend (если не запущен)
```bash
cd mini-app/frontend
npm run dev
```
Frontend должен работать на: `http://localhost:3000`

#### 3. Запуск Telegram бота
```bash
cd basestom/src
python bot.py
```

#### 4. Тестирование в Telegram

**Вариант A: Локальное тестирование (через ngrok)**

1. Установите ngrok: `npm install -g ngrok`
2. Запустите ngrok для Frontend:
   ```bash
   ngrok http 3000
   ```
3. Скопируйте полученный URL (например: `https://abc123.ngrok.io`)
4. Обновите `handlers/mini_app.py`:
   ```python
   LOCAL_MINI_APP_URL = "https://abc123.ngrok.io"  # Ваш ngrok URL
   ```
5. Отправьте `/app` команду в Telegram
6. Нажмите кнопку "Открыть приложение"

**Вариант B: Локальная сеть (только WiFi)**

1. Найдите IP адрес вашего компьютера:
   - Windows: `ipconfig`
   - macOS/Linux: `ifconfig` или `ip addr`
2. Обновите URL:
   ```python
   LOCAL_MINI_APP_URL = "http://192.168.1.X:3000"  # Ваш IP
   ```
3. Убедитесь что компьютер и телефон в одной сети
4. Отправьте `/app` команду в Telegram
5. Нажмите кнопку "Открыть приложение"

### 🐛 Решение проблем:

#### Frontend не запускается:
```bash
# Очистите node_modules и переустановите
cd mini-app/frontend
rm -rf node_modules
npm install
npm run dev
```

#### Backend не отвечает:
```bash
# Проверьте что backend запущен
cd mini-app/backend
python main.py

# Проверьте порт 8000
Test-NetConnection -ComputerName localhost -Port 8000
```

#### Telegram Mini App не открывается:
1. Проверьте что Frontend запущен
2. Проверьте что ngrok запущен
3. Проверьте что URL в mini_app.py верный
4. Проверьте логи бота на ошибки

#### Ошибки в браузере:
- Откройте консоль разработчика (F12)
- Проверьте Console на ошибки
- Проверьте Network на failed requests
- Убедитесь что API отвечает на http://localhost:8000
