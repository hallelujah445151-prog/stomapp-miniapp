## 📁 Новые и улучшенные компоненты

### Общие компоненты (`common/`)
1. **Loader.tsx** - Улучшенный индикатор загрузки с настраиваемым размером
2. **ErrorState.tsx** - Компонент для отображения ошибок с кнопкой повтора
3. **EmptyState.tsx** - Пустое состояние с возможностью действия
4. **Header.tsx** - Заголовок страницы с подзаголовком и действиями
5. **Navigation.tsx** - Bottom navigation bar с активными состояниями
6. **Toast.tsx** - Система toast уведомлений с 4 типами

### Компоненты заказов (`orders/`)
1. **OrderCard.tsx** - Карточка заказа с:
   - Статусом и цветовой индикацией
   - Индикатором срочности
   - Анимацией при нажатии
   - Визуальными иконками

2. **OrderDetails.tsx** - Детали заказа с:
   - Полной информацией о заказе
   - Статусом и сроками
   - Информацией об исполнителях
   - Кнопками редактирования

3. **CreateOrderForm.tsx** - Многошаговая форма создания:
   - 3 логических шага
   - Быстрый выбор операций
   - Контекстные подсказки
   - Предпросмотр перед созданием

4. **EditOrderForm.tsx** - Форма редактирования:
   - Только редактируемые поля
   - Информацией только для чтения
   - Валидацией статуса

### Страницы (`pages/`)
1. **Dashboard.tsx** - Главная страница с:
   - Поиском и фильтрацией
   - Уведомлениями о срочных заказах
   - Статистикой и подсчетами
   - Умной сортировкой

2. **CreateOrder.tsx** - Создание заказа с:
   - 3-шаговым мастером
   - Интеграцией с toast уведомлениями
   - Автоматической загрузкой данных

3. **OrderDetailsPage.tsx** - Страница деталей с:
   - Режимами просмотра и редактирования
   - Обработкой состояний загрузки
   - Навигацией назад
